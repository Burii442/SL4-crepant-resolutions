# Sieves A–J

[Browse all 106 cases](../cases/README.md) · [Catalogue guide](catalogue.md)

The manuscript uses ten sieves to classify the 106 quotient representations: **61 YES and 45 NO**. A case may have more than one applicable sieve; the ten lists contain 112 assignments. The primary sieve is the one printed beside its matrix presentation.

| Sieve | Argument | Outcome |
|---|---|---|
| [A](#sieve-a) | Junior-generation obstruction | NO |
| [B](#sieve-b) | A fixed factor | YES |
| [C](#sieve-c) | Abelian junior-simplex geometry | YES |
| [D](#sieve-d) | Cotangent reflection representations | YES/NO |
| [E](#sieve-e) | Complete-intersection blow-ups | YES |
| [F](#sieve-f) | Double covers | YES |
| [G](#sieve-g) | Determinant extensions | YES |
